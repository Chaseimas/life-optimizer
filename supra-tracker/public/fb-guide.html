Make Facebook hunt Supras for you

Facebook blocks robot scanners, but its own alert system is actually good — set it once and FB notifies you in the FB app the moment someone lists a Supra. Do this on your phone:

  1. Open one of these searches (sign in if asked):
    Phoenix Tucson Las Vegas Los Angeles
  2. On the results page, tap the bell icon (or "Notify me" / save-search toggle).
  3. In the popup, set the radius as wide as it allows (usually 250 miles) and confirm.
  4. Repeat for each city above — between them you've covered the whole Southwest.
  5. Tip: sellers misspell things. Once a week, also search "supra turbo", "mk3 supra", and "1991 toyota" — takes a minute and catches the weird ones.

That's it. Facebook now does the one job this tracker can't.
